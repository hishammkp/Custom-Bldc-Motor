# Custom BLDC Motor Design

A custom **16-slot, 8-pole Brushless DC (BLDC) motor** designed and developed as part of an electrical engineering coursework project. The project involved the complete engineering workflow, including motor design, CAD modeling, 3D printing, stator winding, assembly, simulation, and experimental validation.

## Overview

The objective of this project was to design and fabricate a functional BLDC motor from scratch rather than using a commercially available motor. The stator, rotor, and supporting components were modeled in Onshape, fabricated using 3D printing, assembled with hand-wound copper windings and permanent magnets, and evaluated through simulation and practical testing.

## Features

* Custom 16-slot, 8-pole inner-rotor BLDC motor
* CAD modeling using Onshape
* 3D-printed stator, rotor, and support components
* Hand-wound stator coils with Star (Y) connection
* Electromagnetic simulation and back-EMF analysis
* Prototype fabrication, assembly, and testing
* Iterative design improvements based on experimental observations

| Parameter          | Value                   |

## Challenges & Improvements

During fabrication and testing, manufacturing tolerances led to stator slot breakage, low rotor infill caused instability, and magnets detached at higher speeds. These issues were mitigated through stator modifications, improved magnet retention, and iterative design refinements, resulting in a more robust and reliable prototype.
